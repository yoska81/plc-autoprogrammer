# Bottle filler and capper

Small line: bottles come in on a conveyor, a star wheel or gate holds 4 bottles under 4 filling nozzles, the nozzles go down (air cylinder), we open the fill valves for a set time (we'd like to set the time on a screen, different products need different times), then nozzles go up and the 4 bottles move on to a capping station where a cap is pressed on by an air cylinder, and then out.

Sensors: bottle present at the fill station (need all 4), cap present in the chute, a sensor that sees if a bottle is missing a cap after the capper (reject it with an air blast). The product tank above the nozzles has a low level switch — stop filling if it's low. The conveyor is 1/2 HP 480 V. Everything else is air. We need to be able to run a "clean" mode where the valves open so we can flush. E-stop, guard door on the filler. Count good and rejected bottles.
