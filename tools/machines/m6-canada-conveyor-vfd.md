# Conveyor line (Canada, 600 V)

Plant is in Ontario, 600 V 3-phase. We have three conveyors in a row carrying totes: infeed, accumulation and outfeed. Each conveyor has a 2 HP motor and we want variable speed drives so we can set the speed from the screen and so they start smoothly. Photo eyes at the end of each conveyor. The accumulation conveyor should only run when there's room on the outfeed (zone logic so totes don't crash into each other). Totes are counted at the outfeed.

There's a pull-cord emergency stop along the whole line plus E-stop buttons at each end. Start/stop at the main panel and at the far end. If a drive faults we need to know which one. We want the screen to show each conveyor running/stopped, speeds, tote count, and the faults. Everything must meet Canadian code (CSA).
