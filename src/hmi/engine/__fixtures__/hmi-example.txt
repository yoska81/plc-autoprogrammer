C1001   HMI_Start                    BIT   write      Momentary Start: the PLC starts the automatic cycle when Safety OK (X001) is ON, no alarm is latched and Manual mode is off.
C1002   HMI_Stop                     BIT   write      Momentary Stop: the PLC ends the automatic cycle (stops all motion).
C1003   HMI_Reset                    BIT   write      Momentary Reset: clears latched alarms whose cause is gone. Never restarts anything by itself.
C1004   HMI_Manual_Select            BIT   read-write Toggle from the HMI: ON requests Manual mode; the PLC accepts it only while the cycle is stopped.
C1201   STS_Manual_Mode              BIT   read       PLC sets ON while Manual mode is active (C1004 ON and the cycle stopped); Start is blocked while ON.
C1202   STS_Running                  BIT   read       PLC sets ON while the automatic cycle runs.
C1203   STS_Heartbeat                BIT   read       PLC toggles every second (communication watchdog on the Diagnostics screen).
DS1101  Machine_State                INT   read       PLC writes 0 Stopped, 1 Running, 2 Faulted, 3 Manual, 4 Safety Stop (highest applicable wins).
C1101   ALM_Cycle_Step_Timeout       BIT   read       PLC latches ON when a step of the automatic cycle lasts longer than its timeout (step table on the Program page) and stops the cycle; Reset (C1003) clears it while stopped.
C1102   ALM_Safety_Open              BIT   read       PLC sets ON while Safety OK (X001) is OFF.
C1204   STS_Conveyor_Jog_Permit      BIT   read       PLC sets ON when Manual mode (C1201) active, Safety OK (X001) ON and no other motion (Y002 OFF).
C1005   HMI_Conveyor_Jog             BIT   write      Hold-to-run: while ON and C1204 is ON the PLC energizes Y001 (Conveyor motor contactor); stops on release.
C1205   STS_Pusher_Extend_Permit     BIT   read       PLC sets ON when Manual mode (C1201) active, Safety OK (X001) ON and no other motion (Y001 OFF).
C1006   HMI_Pusher_Extend            BIT   write      Hold-to-run: while ON and C1205 is ON the PLC energizes Y002 (Pusher solenoid); spring return retracts on release.
DS1001  SP_Pusher_Timeout            INT   read-write Seconds allowed for Pusher to reach X005 (Pusher extended) / X006 (Pusher retracted) (1–30, default 3 on the first scan).
C1103   ALM_Pusher_Timeout           BIT   read       PLC latches ON when Pusher does not reach its feedback position within DS1001 seconds after its valve switches; Reset (C1003) clears it.
CTD1    Part_Count                   INT2  read       Counter value: the PLC counts each rising edge of X004 (Part at end photo-eye).
C1007   HMI_Count_Reset              BIT   write      Momentary: resets the part counter CT1.
DS1002  SP_Batch_Target              INT   read-write Batch size in parts (0 = no limit): the PLC stops the cycle when CTD1 reaches it.
DS1102  Parts_Per_Min                INT   read       Parts counted in the last 60 s.
DS1103  Run_Hours                    INT   read       Retentive machine run hours (count while the cycle runs).
DS1104  Hours_Since_Service          INT   read       Retentive run hours since the last Service Done.
DS1003  SP_Service_Interval          INT   read-write Run hours between services (50–2000, default 500 on the first scan).
C1008   HMI_Service_Done             BIT   write      Momentary: resets the hours since service (DS1104) to 0.
C1104   WRN_Service_Due              BIT   read       PLC sets ON when DS1104 >= DS1003.

alarm C1101 alarm: A cycle step did not finish in time
alarm C1102 alarm: Safety circuit open (E-stop or guard)
alarm C1103 alarm: Pusher did not reach its position in time
alarm C1104 warning: Service due: run hours reached
