block safety "Safety & modes"
block alarms "Alarms"
block cycle "Cycle"
block pusher "Pusher"
block manual "Manual"
block outputs "Outputs"
block status "HMI & status"

[safety] First scan: Pusher timeout (s) outside 1-30 is loaded with the default 3
    NO:SC2 DS1001<1 | NO:SC2 DS1001>30  ->  COPY 3->DS1001
[safety] First scan: batch target outside 0-9999 is loaded with the default 0
    NO:SC2 DS1002<0 | NO:SC2 DS1002>9999  ->  COPY 0->DS1002
[safety] First scan: service interval (h) outside 50-2000 is loaded with the default 500
    NO:SC2 DS1003<50 | NO:SC2 DS1003>2000  ->  COPY 500->DS1003
[safety] Safety OK from the safety relay (E-Stop OK (safety relay))
    NO:X001  ->  OUT C1
[safety] Reset command: HMI Reset
    NO:C1003  ->  OUT C7
[safety] Manual mode request is refused while the cycle runs: the HMI toggle is reset
    NO:C2 NO:C1004  ->  RST C1004
[safety] Manual mode active: HMI Manual selected and the cycle stopped
    NO:C1004 NC:C2  ->  OUT C1201
[safety] Cycle running: Start Button or HMI Start seals in; Stop Button (NC), HMI Stop, safety loss, a fault, Manual mode or batch complete drops it
    RISE:X002 NO:X003 NC:C1002 NO:C1 NC:C3 NC:C1201 NC:C4 | RISE:C1001 NO:X003 NC:C1002 NO:C1 NC:C3 NC:C1201 NC:C4 | NO:C2 NO:X003 NC:C1002 NO:C1 NC:C3 NC:C1201 NC:C4  ->  OUT C2
[safety] Running status for the HMI
    NO:C2  ->  OUT C1202
[alarms] Pusher did not reach its position in time: latched
    NO:T1 | NO:T2  ->  SET C1102
[alarms] Pusher timeout reset: Reset once the valve is off
    NO:C7 NC:Y002  ->  RST C1102
[alarms] Safety circuit open alarm while Safety OK is off
    NC:C1  ->  OUT C1101
[alarms] Any fault (stops the cycle): C1102
    NO:C1102  ->  OUT C3
[alarms] Service due warning: hours since service reached the service interval
    DS1104>=DS1003 DS1003>0  ->  OUT C1103
[cycle] Default cycle: Conveyor runs whenever the cycle runs (the machine's own sequence replaces this)
    NO:C2  ->  OUT C20
[cycle] Automatic sequence not written yet: Pusher extend stay off in Auto (the AI or you write this block)
    NC:SC1  ->  OUT C21
[pusher] Pusher: extend timeout — valve on but not at Pusher extended within the setpoint
    NO:C1 NO:Y002 NC:X005  ->  TMR T1 DS1001sec
[pusher] Pusher: retract timeout — valve off but not at Pusher retracted within the setpoint
    NO:C1 NC:Y002 NC:X006  ->  TMR T2 DS1001sec
[manual] Conveyor: Jog permitted — Manual mode, Safety OK, no other motion
    NO:C1201 NO:C1 NC:Y002  ->  OUT C1204
[manual] Conveyor: manual Jog (Conveyor motor contactor) while the HMI button is held and permitted
    NO:C1005 NO:C1204  ->  OUT C23
[manual] Pusher: Extend permitted — Manual mode, Safety OK, no other motion
    NO:C1201 NO:C1 NC:Y001  ->  OUT C1205
[manual] Pusher: manual Extend (Pusher solenoid) while the HMI button is held and permitted (an earlier jog has priority)
    NO:C1006 NO:C1205 NC:C23  ->  OUT C24
[outputs] Conveyor motor contactor: automatic (cycle running) or manual request, Safety OK
    NO:C20 NO:C2 NO:C1 | NO:C23 NO:C1  ->  OUT Y001
[outputs] Pusher solenoid: automatic (cycle running) or manual request, Safety OK
    NO:C21 NO:C2 NO:C1 | NO:C24 NO:C1  ->  OUT Y002
[outputs] Main air dump valve: on only while Safety OK (loss of safety exhausts the air)
    NO:C1  ->  OUT Y003
[status] One-scan pulse on each rising edge of the 1 s system clock SC7
    RISE:SC7  ->  OUT C6
[status] PLC heartbeat for the HMI: changes state every second
    NO:C6 NC:C1203 | NC:C6 NO:C1203  ->  OUT C1203
[status] Machine state 0 Stopped (default, overwritten below by higher states)
    NO:SC1  ->  COPY 0->DS1101
[status] Machine state 1 Running
    NO:C2  ->  COPY 1->DS1101
[status] Machine state 3 Manual
    NO:C1201  ->  COPY 3->DS1101
[status] Machine state 2 Faulted
    NO:C3  ->  COPY 2->DS1101
[status] Machine state 4 Safety Stop
    NC:C1  ->  COPY 4->DS1101
[status] Part counter: each part at Part at end photo-eye, reset from the HMI
    NO:X004  ->  CNT CT1 rst C1007
[status] Batch complete: a batch target is set and the part count reached it
    DS1002>0 CTD1>=DS1002  ->  OUT C4
[status] Rate window timer: 10 s, restarts itself
    NC:T3  ->  TMR T3 10sec
[status] Every 10 s: shift the six 10 s buckets and store the parts counted in the last 10 s
    NO:T3  ->  COPY DS1125->DS1126, COPY DS1124->DS1125, COPY DS1123->DS1124, COPY DS1122->DS1123, COPY DS1121->DS1122, MATH DS1121=CTD1 - DS1119, COPY CTD1->DS1119
[status] A count reset makes the newest bucket negative: count it as 0
    NO:T3 DS1121<0  ->  COPY 0->DS1121
[status] Parts per minute DS1102: the six 10 s buckets
    NO:T3  ->  MATH DS1102=DS1121 + DS1122 + DS1123 + DS1124 + DS1125 + DS1126
[status] Run-hour timer: accumulates while the cycle runs, restarts after each full hour
    NO:C2  ->  TMR T4 3600sec
[status] One full run hour reached
    NO:T4  ->  OUT C5
[status] Add the hour to the run hours and the hours since service
    NO:C5  ->  MATH DS1103=DS1103 + 1, MATH DS1104=DS1104 + 1
[status] HMI Service Done clears the hours since service
    NO:C1008  ->  COPY 0->DS1104

C1 Safety_OK: Safety relay healthy
C7 Cmd_Reset: Reset from the HMI or the panel
C2 Cycle_Running: Automatic cycle running
C20 Auto_Conveyor_run: Automatic run request for Conveyor (set by the cycle block)
C21 Auto_Pusher_extend: Automatic extend request for Pusher (set by the cycle block)
T1 Tmr_Pusher_Ext: Pusher extend timeout
T2 Tmr_Pusher_Ret: Pusher retract timeout
C22 Auto_Main_Air_Dump_run: Automatic run request for Main Air Dump (set by the cycle block)
C3 Any_Fault: A latched fault: stops the cycle
C23 Man_Conveyor_Y001: Manual request Conveyor motor contactor
C24 Man_Pusher_Y002: Manual request Pusher solenoid
C6 Pulse_1s: One scan every second
C4 Batch_Done: Batch target reached
T3 Tmr_Rate: 10 s rate window
T4 Tmr_Run_Hour: Run-hour timer
C5 Run_Hour_Pulse: One run hour reached

note: The automatic sequence for Pusher is not written yet: those actuators move only in Manual until the cycle block is written.
