    NO:C2  ->  TMR T3 3600sec
[status] One full run hour reached
    NO:T3  ->  OUT C5

    NO:C5  ->  MATH DS1102=DS1102 + 1, MATH DS1103=DS1103 + 1
[status] HMI Service Done clears the hours since service
    NO:C1008  ->  COPY 0->DS1103

C1 Safety_OK: Safety relay healthy
C7 Cmd_Reset: Reset from the HMI or the panel
C2 Cycle_Running: Automatic cycle running
C20 Auto_Unwinder_run: Automatic run request for Unwinder (set by the cycle block)
C21 Auto_Head_extend: Automatic extend request for Head (set by the cycle block)
C22 Auto_Head_retract: Automatic retract request for Head (set by the cycle block)
T1 Tmr_Head_Ext: Head extend timeout
T2 Tmr_Head_Ret: Head retract timeout
C23 Auto_Heater_run: Automatic run request for Heater (set by the cycle block)
C3 Any_Fault: A latched fault: stops the cycle
C24 Man_Unwinder_Run: Manual request Unwinder motor run
C25 Man_Head_Down: Manual request Head down solenoid
C26 Man_Head_Up: Manual request Head up solenoid
C6 Pulse_1s: One scan every second
T3 Tmr_Run_Hour: Run-hour timer
C5 Run_Hour_Pulse: One run hour reached
DS1150 Step_Cycle: Automatic cycle step (0 idle, 10, 20…)
CT1 Cnt_Cycles: Completed automatic cycles
T4 Tmr_Step_10: Step 10 time
T5 Tmr_Step_20_Tmo: Step 20 timeout
T6 Tmr_Step_30: Step 30 time
T7 Tmr_Step_40_Tmo: Step 40 timeout
