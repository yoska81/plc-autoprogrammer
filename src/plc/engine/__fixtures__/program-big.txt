C1 Safety_OK: Safety relay healthy
C7 Cmd_Reset: Reset from the HMI or the panel
C2 Cycle_Running: Automatic cycle running
C20 Auto_Belt_1_run: Automatic run request for Belt 1 (set by the cycle block)
C21 Auto_Belt_1_reverse: Automatic reverse request for Belt 1 (set by the cycle block)
C22 Auto_Belt_2_run: Automatic run request for Belt 2 (set by the cycle block)
C23 Auto_Belt_3_run: Automatic run request for Belt 3 (set by the cycle block)
C24 Auto_Gripper_extend: Automatic extend request for Gripper (set by the cycle block)
C25 Auto_Gripper_retract: Automatic retract request for Gripper (set by the cycle block)
T1 Tmr_Gripper_Ext: Gripper extend timeout
T2 Tmr_Gripper_Ret: Gripper retract timeout
C3 Any_Fault: A latched fault: stops the cycle
C26 Man_Belt_1_Y001: Manual request Belt 1 VFD run
C27 Man_Belt_1_Y004: Manual request Belt 1 VFD reverse
C28 Man_Belt_2_Y002: Manual request Belt 2 VFD run
C29 Man_Belt_3_Y003: Manual request Belt 3 VFD run
C30 Man_Gripper_Y005: Manual request Gripper close solenoid
C31 Man_Gripper_Y006: Manual request Gripper open solenoid
C6 Pulse_1s: One scan every second
C4 Batch_Done: Batch target reached
T3 Tmr_Rate: 10 s rate window
T4 Tmr_Run_Hour: Run-hour timer
C5 Run_Hour_Pulse: One run hour reached
DS1150 Step_Cycle: Automatic cycle step (0 idle, 10, 20…)
CT2 Cnt_Cycles: Completed automatic cycles
T5 Tmr_Step_20_Tmo: Step 20 timeout
T6 Tmr_Step_30_Tmo: Step 30 timeout
